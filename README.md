# Simple Interest Calculator

A simple bash script that calculates simple interest given principal amount, annual rate of interest, and time period in years.

## Formula
```text
Simple Interest (I) = (P × T × R) / 100
Total Amount = P + Simple Interest
```

Where:
- **P** = Principal amount
- **T** = Time period in years
- **R** = Annual rate of interest (%)

---

## Input & Output

### Inputs
1. `p` - Principal amount (e.g., 1000)
2. `t` - Time period in years (e.g., 2)
3. `r` - Annual rate of interest (e.g., 5)

### Output
- `Simple Interest` = Calculated interest value
- `Total Amount` = Principal + Simple Interest

---

## How to Run

1. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```

2. Execute the script:
   ```bash
   ./simple-interest.sh
   ```

3. Follow the interactive prompts to enter principal, interest rate, and time period.
